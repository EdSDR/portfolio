## Overview

Polaris is a clean, high-contrast portfolio template: a sticky bio column on the
left, a scrolling column of large hero cards on the right. It puts the work first
and keeps the chrome quiet.

## The idea

I wanted a layout that reads like a printed editorial spread but behaves like a
fast, modern web app. Monochrome neutrals, a single accent, generous whitespace,
and typography doing most of the talking.

- Two-column shell that collapses gracefully to a single column on mobile.
- Hero cards with rounded corners and a soft halftone treatment.
- A neutral OKLCH palette with one emerald accent.

## Why it's here

This project is the design north star for the site you're looking at — same bones,
but every hero is now a live 3D scene instead of a static image.

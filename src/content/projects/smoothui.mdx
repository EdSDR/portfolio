## Overview

SmoothUI is a small library of React components that feel alive — buttons, cards,
and inputs with spring-based motion that stays out of the way until you touch it.

## Principles

- Motion should confirm an action, never decorate for its own sake.
- Every animation respects `prefers-reduced-motion`.
- Transforms and opacity only — no layout thrash, no jank.

## Under the hood

Built on the `motion` library with a thin styling layer, each component ships with
sensible defaults and a handful of variants so it drops into an existing design
system without a fight.
